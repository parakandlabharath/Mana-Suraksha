# Web Client — Planned

This directory is reserved for the browser client. The web application has not been implemented yet.

## Planned screens
- Home and language selection (Telugu / English).
- SMS checker, URL checker and phone-number lookup.
- Explainable results with reasons, limitations and safe next steps.
- Fraud report submission and personal report status.
- Moderator review queue with role-protected actions.

## UX principles
Use plain language, large touch targets, accessible contrast, responsive layout and clear loading/error/unknown states. Never display a numeric score without an explanation. Do not automatically open submitted URLs.
