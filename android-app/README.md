# Android Client — Planned

This directory is reserved for the Android application. The Android app has not been implemented yet.

## Planned first features
- Telugu / English language selection.
- Share-to-check or paste SMS text with an explicit privacy warning.
- URL and phone-number checks through the API.
- Fraud reporting and status tracking.
- Offline safety guidance.

## Call-screening note
Call screening is a later opt-in milestone. It must use supported Android APIs and user-granted role/permissions. Device and OS support vary. Do not claim that the app can identify or block every scam call. Caller ID can be spoofed.

## Privacy
Do not request broad inbox access for the first version. Never collect OTPs, PINs, passwords or banking credentials.
